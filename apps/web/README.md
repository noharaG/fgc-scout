# apps/web

利用者が見る画面。取得済みデータの絞り込みと並べ替え、推定の計算、表示を担う。

## 役割ごとの依存

役割ごとに1つだけ選ぶ。**この表に無い役割の依存を足さない。**
依存を足すコミットで、この表に行を足す。

| 役割             | 選ぶもの                                                      |
| ---------------- | ------------------------------------------------------------- |
| UI ランタイム    | React 19                                                      |
| ルーティング     | TanStack Router（ファイルベース＋検索パラメータの型付き検証） |
| サーバ状態       | TanStack Query                                                |
| スタイル         | Tailwind CSS v4 ＋ `src/styles/globals.css` 1枚               |
| API クライアント | `hono/client`（`api` パッケージのルート型から導出）           |
| ビルド           | Vite（vite-plus 経由）                                        |

### 未決定

| 役割                                   | 状態                                                          |
| -------------------------------------- | ------------------------------------------------------------- |
| 対話部品（ダイアログ・ポップオーバー） | 必要になるまで入れない。入れるときはヘッドレスのものを1つだけ |
| 図・チャート                           | 未定。推定の内訳を図にする段で決める                          |

状態管理ライブラリは**持たない。**サーバ状態はクエリライブラリが、
URL 状態はルータが持つので、グローバルストアの仕事が残らない。

## ディレクトリ

| パス                     | 役割                                                      |
| ------------------------ | --------------------------------------------------------- |
| `src/main.tsx`           | 入口。1ファイル。スタイルシートの副作用 import もここだけ |
| `src/routes/`            | 1 URL に1ファイル。ファイル名がそのまま URL になる        |
| `src/client/`            | ネットワーク越しの型付きクライアント。1ファイル1行に限る  |
| `src/styles/globals.css` | リポジトリで唯一の CSS                                    |
| `src/routeTree.gen.ts`   | ルータのプラグインが生成する。手で編集しない              |
| `public/`                | URL パスで固定名のまま配る物だけ                          |

## 置かないもの

| もの                                     | 正しい置き場                                                             |
| ---------------------------------------- | ------------------------------------------------------------------------ |
| 認可の判断                               | `apps/api`。画面側の出し分けは表示の都合であって認可ではない             |
| 公式データの取得                         | `apps/api`。相手のサイトは CORS ヘッダを返さないのでブラウザから叩けない |
| 見た目の正本                             | `prototype/fgc-scout/`。実装はそこから転写する                           |
| 2つ目の CSS ファイル                     | 無い。`globals.css` 1枚に集約する                                        |
| 業務機能ごと・技術種別ごとのディレクトリ | 作らない。`src` 直下は「越える境界」で切る                               |

## 最も破られやすい境界

規約が「最も破られやすい境界」と書いている箇所を、逐語で写す。

> **推定値を実測値として表示しない。** 数字の隣に出典（公式 / 推定 / 申告）を
> 必ず添える。区別が消えると「登れると言っていた」ことと「登れた」ことが
> 同じ重みで読まれ、作戦の判断を誤る。

この境界はこのパッケージにある。数字を出すすべての箇所が対象で、
`ui-source-tag` クラスがその機構である。装飾ではない。

## 手順

### 開発サーバを起動する

```sh
pnpm run dev
```

`/api` は `http://127.0.0.1:8787` へ同一オリジンでプロキシされる。
API 側を別のターミナルで起動しておく（`apps/api/README.md`）。

### 成果物を作る

```sh
pnpm run build
```

出力先は `dist/`。Worker がこのディレクトリを静的資産として配る。

### ブラウザテストを流す

API を起動した状態で、`apps/api/.dev.vars` に入れたのと同じパスワードを
環境変数で渡す。パスワードはテストに書き込まない。

```sh
E2E_VIEWER_PASSWORD="共有パスワード" \
E2E_ADMIN_PASSWORD="管理者パスワード" \
pnpm -C apps/web exec playwright test
```
